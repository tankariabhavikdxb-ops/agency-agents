REST API quick reference (for Phase 2 development) 
GET  /api/health                          system + connectivity status
GET  /api/companies                       open companies in Tally
POST /api/companies/{company}/select      subscribe to live sync
GET  /api/{company}/ledgers|groups|stock-items|stock-groups|units|currencies
GET  /api/{company}/cost-centres|cost-categories|godowns|voucher-types
POST /api/{company}/ledgers               create ledger      {name, parent, ...}
PUT  /api/{company}/ledgers/{name}        alter ledger
DEL  /api/{company}/ledgers/{name}        delete ledger
POST /api/{company}/stock-items           create stock item
GET  /api/{company}/vouchers?type=&from_date=&to_date=&page=&page_size=
POST /api/{company}/vouchers              create voucher {voucher_type, date,
                                            ledger_entries:[{ledger_name,amount,is_debit}], narration}
PUT  /api/{company}/vouchers/{remote_id}  alter voucher
POST /api/{company}/vouchers/delete       delete {remote_id | voucher_number+voucher_type+date}
GET  /api/{company}/day-book?date=
GET  /api/{company}/ledger-vouchers/{ledger}
GET  /api/{company}/reports/trial-balance|balance-sheet|profit-loss
GET  /api/{company}/dashboard             aggregated home-screen stats
GET  /api/sync/status                     sync engine internals
WS   data_changed                         push event on any Tally-side change
