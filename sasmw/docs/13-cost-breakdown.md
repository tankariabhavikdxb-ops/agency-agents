---

## Bottom line (minimum to launch)

| Scenario | Approx. first-year cost |
|----------|-------------------------|
| **Starter (recommended)** — hosting + domain + email + free stack | **~$120–210 USD total** (~MWK 100k–190k) |
| **With FooEvents** (premium tickets + check-in) | add ~$99/yr |
| **Ongoing renewal** (hosting + domain + email) | ~$120–210/yr |

> Everything on the site itself is **$0** in software — your real recurring costs
> are hosting, domain, and email. This is a lean startup budget.

---

## Optional paid upgrades (later, when revenue supports them)
- Elementor Pro (~$59/yr) — theme builder, advanced widgets, popups.
- FooEvents (~$99/yr) — branded PDF tickets + stadium check-in app.
- Cloudflare CDN Pro — only if you outgrow free tier.
- React Native / Flutter app — future phase (see your roadmap).
