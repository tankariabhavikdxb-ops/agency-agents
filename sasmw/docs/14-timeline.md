# Timeline Estimate

Realistic timeline for a single operator doing this alongside a day job. Parallel
tasks (where noted) speed things up.

| Week | Milestone | Effort |
|------|-----------|--------|
| **Week 1** | Phase 1: hosting, domain, SSL, email; **start Airtel developer-portal registration + business docs (parallel — this is the longest pole)** | 1–2 days |
| **Week 2** | Phase 2–3: theme + Elementor, install plugin set | 2–3 days |
| **Week 3** | Phase 4: WooCommerce MWK config + create 5 match products | 2–3 days |
| **Week 4** | Phase 5: install + configure Airtel plugin; sandbox tests | 2–3 days |
| **Week 5** | Phase 6–7: e-ticket/QR verified; news + 5 articles + ticker | 3 days |
| **Week 6** | Phase 8: mobile + PWA + performance | 2–3 days |
| **Week 6–7** | Phase 9–10: SEO, analytics, social, paste content, personalise legal pages | 2–3 days |
| **Week 7** | Run testing checklist; fix issues | 2–3 days |
| **Week 8** | **GO LIVE**; post-launch monitoring | 1 day |

**Total: ~6–8 weeks part-time (2–4 hours/day), or ~2–3 weeks full-time.**

> ⏳ **Critical path:** Airtel production API approval (business docs + KYC) can take
> **1–4+ weeks** and sometimes more. **Start it on Day 1.** If it's not approved by
> launch, go live with **manual confirmation** (or PayChangu) so you can sell
> immediately, then switch to full automation when Airtel callbacks are live.

---

## If you must launch FAST (2-week sprint)
1. **Day 1:** Buy hosting + domain, install WP + SSL + email. Submit Airtel business
   docs the same day.
2. **Days 2–4:** Theme + plugins + WooCommerce MWK config.
3. **Days 5–8:** Create 5 matches; install + configure Airtel plugin (manual/test mode).
4. **Days 9–11:** Publish content + legal pages + 5 articles + ticker.
5. **Days 12–13:** Testing checklist + fixes.
6. **Day 14:** Go live (manual confirmation until Airtel automation is ready).
